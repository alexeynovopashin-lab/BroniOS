# BroniOS → ядро: каталог студий с неподключёнными студиями

8 октября 2026. Дополнение к требованиям ядра (`BroniOS_core_requirements.md`), сливает тред, который ведёт этот файл. Обозначения: **Решено** = слова Алексея; **Предложение** = мысль Claude; **Не проверено** = нужно выяснить до работы.

## Решение Алексея (08.10, дословно)

«У AppEvent есть каталог фотостудий, то есть это готовая горячая база потенциальных клиентов. Также есть база VK, Яндекса и 2ГИС. Это надо учесть на будущее. Нам тоже потребуется свой агрегатор фотостудий. Только мы сделаем умнее. Мы добавим туда и подключённые фотостудии и не подключённые. Студии, которые не были подключены, получат от нас уведомление, что клиенты нашли их в нашем каталоге, вот вам промокод на 3 месяца работы виджета.»

Это **на будущее**, не текущий этап. Устаревает прежнее правило «неподключённые студии нигде не показываются» (в том числе строка в `BroniOS_studio_onboarding.md`, раздел «Как владелец попадает в мастер»).

## Что нужно от ядра (предложение)

1. **Карточка студии без владельца.** Студия в каталоге может существовать без хозяина: название, адрес, точка на карте, залы (если известны), откуда взяты данные (AppEvent / VK / Яндекс / 2ГИС / фотограф) и дата. Бронировать в ней нельзя.
2. **Третий путь подключения — «это моя студия».** К двум путям из блока 26 (приглашение и самостоятельный вход) добавляется: владелец открывает уведомление, подтверждает, что студия его, и проходит тот же мастер с уже заполненными полями. После «Открыть запись» карточка становится подключённой, история каталога (просмотры, «клиенты нашли») сохраняется.
   - Пример: студия «Белый куб» лежит в каталоге с адресом из 2ГИС. За месяц её карточку открыли 40 раз. Владелец получает письмо «Клиенты нашли вас в каталоге», переходит по ссылке, подтверждает, мастер открывается с адресом и названием.
3. **Счётчик «клиенты нашли вас»** у неподключённой студии: сколько раз открыли карточку. Без данных о самих клиентах.
4. **Промокод на работу виджета.** Код, привязанный к студии, на срок (3 месяца по словам Алексея). Ядро уже закладывает два тарифа (токены и подписка, 06.10): на подписке это 3 месяца бесплатно. **Решено (Алексей, 08.10, вариант А):** на токенах — 3 месяца брони не списывают токены, реклама и рассылки платные как обычно. Ядру нужно: у промокода дата начала и конца, и пока он действует, пришедшая бронь не списывает токен (но считается, как обычно, для статистики).
5. **Студия может убрать себя из каталога** (предложение): кнопка в уведомлении «Не показывать нас».
6. **Рейтингов нет** — без изменений (вопрос 5, вариант А).

## Не проверено

- Можно ли законно брать данные из каталога AppEvent, VK, Яндекса, 2ГИС (условия сервисов, 152-ФЗ, если там есть телефоны и имена людей).
- Можно ли писать студии, которая к нам не подключалась, и каким каналом (закон о рекламе, правила площадок).

Ничего не собираем и никому не пишем, пока Алексей не скажет.
