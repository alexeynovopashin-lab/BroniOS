# BroniOS → ядро: дополнения из подключения новой студии

8 октября 2026 · из треда «Подключение новой студии». Отдельный файл, чтобы не мешать правкам `BroniOS_core_requirements.md`; сливать туда как блок 26 (координатор). Всё ниже **предложения**, кроме помеченного «Решено». Алексей одобрил 08.10 («ок»): черновик студии, пробную бронь и правило таймера — их считать решёнными.

### 26. Подключение студии: черновик, приглашение, готовность

- **Студия в черновике.** У студии признак «запись открыта / закрыта». Пока закрыта: окно брони и страница записи клиентам не отвечают, по API студия не видна. Хозяин открывает и закрывает запись сам.
- **Два пути входа (Решено, Алексей 08.10: «Оба варианта, можем прислать ссылку, клиент сам может найти нас»).** (а) Одноразовая ссылка-приглашение с автором (Алексей или фотограф `id<номер>`) и, если есть, заготовкой карточки студии, которую фотограф ввёл у себя. (б) Самостоятельная регистрация без ссылки. (в) «Это моя студия» из каталога (Алексей 08.10, на будущее; детали в `BroniOS_core_catalog_additions.md`, п. 2): мастер заполняется из карточки каталога. Во всех случаях тот, кто ввёл код, становится хозяином новой `pl<номер>`. Нужна проверка, что одну и ту же студию не подключили дважды (совпадение адреса или точки → «такая студия уже есть, попросите хозяина добавить вас»).
- **Таймер черновика (Решено, Алексей 08.10: «Пустые и случайные студии живут по таймеру, например 12 часов»).** Предложение по правилу: студия без «Открыть запись» удаляется через 12 часов после последнего действия (число настраивается платформой, 12 тестовое); планировщик (блок 6) шлёт хозяину напоминание за час; открытая студия под таймер не попадает; на пути (в) удаляется только черновик настройки, карточка каталога остаётся.
- **Часовой пояс из точки.** Ядро определяет пояс по координатам точки студии (имя пояса, например `Asia/Novosibirsk`), владелец может поправить.
- **Пробная бронь.** Флаг брони «проба»: проходит весь путь (виджет, страница брони, админка), не считается в статистике, не списывает токен, удаляется через N дней (число не решено).
- **Готовность студии.** Ядро отдаёт список обязательных и необязательных пунктов с отметкой «заполнено» (залы ≥ 1 с ценой, часы работы, способ оплаты, правила, политика и реквизиты), чтобы и BroniOS, и сайт показывали один и тот же список.
- **Реквизиты студии.** Форма (самозанятый / ИП / ООО), ФИО или название, ИНН, реквизиты для перевода. Хранятся в закрытой части, видны хозяину и директору; реквизиты для перевода показываются клиенту только внутри его брони. Решено (07.10): реквизиты подставляются в шаблон политики платформы.
- **Внешний календарь только на чтение при подключении.** То же, что «призраки» в блоке 4, но запускается из мастера: ссылка на Google Календарь или .ics AppEvent.
- **Стартовый баланс токенов.** Ядру нужна возможность задать стартовое число токенов новой студии. **Не решено:** само число, подарок или ноль.
