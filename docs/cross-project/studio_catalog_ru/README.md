# Фотостудии городов России, Беларуси и Казахстана — черновой список, 2026-11-04

Черновик для выбора студии в Light Plan. Алексей проверяет вручную; ничего здесь не проверено звонком или визитом.
Томск собран подробнее и лежит отдельно: `../studio_catalog_tomsk/`.

Условия использования StudioGo и 2ГИС **не проверены**. Телефонов здесь нет (репозиторий публичный): они в отдельных файлах вне репозитория (правило 8).

## Что в файле города (`<город>.json`)
- `studios` — список: `name` (название), `address` (адрес; этаж/офис, если источник их даёт), `halls` (названия залов), `src` (откуда), иногда `hallsCount`, `formerNames`, `note`.
- `closed` — закрытые студии, если источник это показывает.
- Источники: **StudioGo** (каталог студий под аренду: адрес, залы) и **выдача 2ГИС** по рубрике «Фотостудии» (только название и адрес до дома) — 2ГИС добирается там, где в StudioGo меньше 10 студий.

## Правила
1. **Пустой список залов** = у студии один зал с её названием (правило Алексея 04.11). Если залов несколько, а названия неизвестны — `hallsCount`.
2. **Студия = место**: адрес + этаж/офис. Название — свойство места, а не наоборот.
3. **Сменилось название на том же месте** (тот же дом и тот же офис; если офис неизвестен — тот же дом и совпадает этаж или хотя бы один зал): **одна запись**. `name` — текущее название (по самому свежему источнику: слова Алексея → открытая карточка 2ГИС/Яндекса → StudioGo → выдача 2ГИС → Gorko), прежние — в `formerNames`. Дубль не создаётся.
4. **Закрытая студия**: если на её месте есть новая — правило 3 (старое имя в `formerNames`); если преемника нет — в `closed`.
5. **Один дом, разные офисы или разные названия без данных об офисе** — разные студии (в одном здании бывает 10 студий). Сливать только по правилу 3. В сомнении — не сливать, а написать `note`: «возможно, то же место, что …».
6. **Одно название на разных адресах** — разные записи (филиалы), `note`: «филиал».
7. Ничего не выдумывать: нет данных — поле пустое.
8. **Телефоны не лежат в репозитории** (он публичный, а у малых студий это часто мобильный номер администратора). Они собираются со страницы студии на StudioGo (ссылка `tel:` или открытый текст) в отдельные файлы `phones_<город>.json` вне репозитория: `{"phones": {"studiogo:<ID>": "+7…"}, "notFound": ["studiogo:<ID>"]}`. Ключ — запись из поля `src`, по нему номер связывается со студией. Алексей по этим номерам заводит id.
9. **Смена хозяина на том же месте** (номер новый): запись остаётся одна (правило 3), id берётся от текущего номера, прежние название и номер хранятся в «прежних». Студия без найденного номера — `notFound`, id заводит Алексей вручную.
