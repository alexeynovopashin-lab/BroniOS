## 3. Правила, по которым собрано
- Студия — это место. Сменилось название на том же месте: одна запись, прежние названия отдельно. В одном доме разные студии не сливаются.
- Одно название на разных адресах — разные записи с пометкой «филиал».
- Номера не лежат в репозитории (он публичный). Ключ в файле номеров — `studiogo:<ID>`.
- Запросы к каждому сайту шли строго по одному. Лимит частоты сработал один раз на StudioGo и ни разу на 2ГИС в этой серии. `robots.txt` и блокировки не обходил.

- Выдача 2ГИС прочитана не до конца: Нижний Новгород 4 из 12 страниц, Воронеж 4 из 7, Челябинск 4 из 7, Тольятти 5 из 6, Астана 5 из 8.

- Фильтр «не студия» применялся только к 2ГИС. В списках StudioGo есть студии танцев, подкастов и т. п.
- Сомнительные пары помечены `note` («возможно, то же место», «филиал»), автоматически я их не сливал.
- 30 групп студий делят один номер (один владелец). Если id заводятся по номеру, они совпадут.
- Мои ошибки по ходу: общее число записей один раз назвал 1263 вместо 1467 (исправлено); один помощник ошибся в остатке очереди (проверил по файлам).
