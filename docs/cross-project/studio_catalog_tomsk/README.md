## Что не получилось

- **Сторона света окон: нет ни у кого, кроме Томсона.** Открытые описания говорят «солнечная сторона», «много света» — азимута нет. Свет в окне (`window_light`) для них посчитать нельзя; честная подпись — «нет данных» (как в договоре `window_light`).
- **Площади по залам** у Studio flat 101 и Мгновений нет; у нескольких студий площадь студии и зала в карточке расходятся.
- **15 студий** — только названия.
- **Не использовано сознательно:** `photoplace.pro` и вторая страница `gorko.ru` запрещены их `robots.txt`; 2ГИС и Яндекс.Карты — их условия на сбор данных я не проверял, поэтому массово оттуда не брал (одну карточку 2ГИС читал только для проверки адреса, в данные она не попала). AppEvent и ВК не смотрел: каталог AppEvent без входа не нашёлся поиском, ВК-группы требуют отдельного разбора.
- Законность использования данных StudioGo/Gorko/2ГИС как источника для нашего каталога: **не проверено**.

## Как заполнить пробелы

1. **Звонок или сообщение в студию** с одним вопросом: «Окна зала на какую сторону? Площадь зала?» — самый надёжный путь (минута на студию, 14 студий).
2. **Замер компасом Light Plan** на месте (решение A-004: после шага 31в) — для тех студий, которые согласятся; результат приходит от самой студии/фотографа и помечается «замерено».
3. **Спутниковый снимок + адрес**: окна на фасаде видны не всегда; вывод приблизительный, помечать «по снимку, не проверено».
4. **Студия сама** присылает данные, когда получит уведомление и промокод (развилка ниже).
