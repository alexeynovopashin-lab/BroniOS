# Развёртка экранов BroniOS (09.10.2026)

Листы для правки дизайна. Открыть в браузере: колесо или щипок — масштаб, перетаскивание — сдвиг,
клавиша 0 — всё сразу, сверху кнопки групп, акцентный цвет и тема. Логики нет, только разметка.
Все имена, телефоны и суммы тестовые.

- razvertka_klient.html — страница брони клиента (8 состояний, 8 окон, плательщик, компьютер)
- razvertka_okno_broni.html — окно брони для сайтов (45 экранов)
- razvertka_adminka.html — админка (вкладки, окна, компьютер)
- razvertka_podklyuchenie_studii.html — подключение студии (23 экрана)
